### Audit Dimensions

1. **Hallucination Detection**: For each non-trivial claim in L0-L2 outputs (every conclusion, every numeric assertion, every attribution):
   - Find explicit supporting text in mineru markdown
   - If unsupported → flag as `UNSUPPORTED`
   - If contradicted → flag as `CONTRADICTED`
   - If partially supported → flag as `WEAKLY_GROUNDED`

2. **Cross-Scene Consistency**: Compare conclusions across scene outputs:
   - Do tech-stack and section-analysis agree on the core methodology?
   - Does evidence-check align with quick-scan's findings?
   - Flag any contradictory statements with source scenes

3. **Coverage Check**: Against archetype.json priority flags:
   - Were all priority sections analyzed?
   - Were all boosted quadrants adequately covered?
   - Were recommended scenes executed?

4. **Data Grounding**: For each numeric citation in outputs:
   - Can it be traced to a specific line/paragraph in mineru markdown?
   - Calculate grounding score: (grounded claims / total claims) × 100
